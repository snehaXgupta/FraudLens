Introduction

Introducing AuthentiX & FraudLens

  • An intelligent platform designed to combat the growing issue of fraudulent and computer-generated online reviews.
  • Employs Natural Language Processing (NLP) to pre-process and extract syntax markers from unstructured feedback.
  • Integrates active machine learning vector pipelines for classification outputs.
  • Supports voice review processing and web-scraping for seamless consumer usage.

Intelligent Prediction

Evaluates token density and structural characteristics to flag synthetic reviews generated by bots or copy farms.

Sentiment Analysis

Correlates positive/negative emotion levels to identify extreme reviews that commonly match commercial manipulation.

Context & Significance

The E-Commerce Review Crisis

  • E-Commerce growth has turned online reviews into the single most influential driver of customer buying choices.
  • Competitors and merchants routinely buy artificial feedback packs to boost search visibility or trash rivals.
  • Generative AI tools (LLMs) make it simple for sellers to script highly plausible, organic-sounding reviews at near-zero cost.
  • AuthentiX acts as a trust verifier, helping buyers inspect language signals and uncover the real truth.

Backend Details

Technical Implementation

Data Pipeline

  • Dataset Construction: Combines fake reviews (labeled CG/OR) and Amazon reviews (filtered by ratings).
  • Cleaning: Regex strips special characters; NLTK eliminates stopwords.
  • Vectorization: TfidfVectorizer fit with max 5000 features.
  • Scraping Framework: Static HTML via BS4, dynamic pages handled by Selenium WebDriver.

Model Optimization

  • Logistic Regression: Chosen model, achieving great execution speed and high accuracy score.
  • Random Forest: Built with 100 trees to evaluate complex features.
  • Multinomial Naive Bayes: Serves as the baseline model.
  • Flask Serving: Weights exported as pickles (joblib) for REST API queries.

Challenges

System Limitations

Scraper Reliability

  • E-commerce websites change layouts frequently, breaking specific scraping selector lines.
  • Anti-scraping layers (CAPTCHAs/Cloudflare) block automatic crawling IP requests.
  • Dynamic SPA sites require heavy Selenium runtime engines on deployment hosts.

Algorithmic Limits

  • The models are trained exclusively on English texts; no support for multi-language comments.
  • TF-IDF vectorizer analyzes frequency and ignores deep grammatical context or sarcasm.
  • Degrades to a rule-based mock engine if deployment servers run out of RAM.
